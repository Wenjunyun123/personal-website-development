This context defines the language for a personal website whose purpose is to build trust and attract high-quality opportunities.

## Language

**High-quality opportunity**:
A serious career, collaboration, consulting, or social-capital opportunity from someone who already has enough trust to take the next step.
_Avoid_: Generic traffic, casual attention, vanity metrics

**Hiring audience**:
Recruiters, interviewers, hiring managers, and headhunters evaluating whether the site owner is worth interviewing or advancing for a role.
_Avoid_: General followers, casual visitors, broad creator audience

**AI frontend engineer**:
A frontend engineer who uses AI systems, automation, and product-oriented interfaces to build polished, useful software experiences.
_Avoid_: Generic full-stack engineer, pure visual designer, AI hobbyist

**AI product interface**:
A real user-facing interface that turns AI capability into a usable workflow, with clear inputs, outputs, states, and feedback.
_Avoid_: AI demo, chatbot wrapper, visual gimmick

**Project case**:
A real project, plugin, or tool presented as evidence of problem framing, product thinking, interface execution, and technical delivery.
_Avoid_: Screenshot dump, task list, generic portfolio item

**End-to-end delivery**:
The complete path from ambiguous need to product experience, interface design, implementation, and verifiable outcome.
_Avoid_: Isolated code task, visual-only showcase, feature checklist

**Selected case set**:
The three strongest project cases chosen to prove the site owner's target positioning to the hiring audience.
_Avoid_: Exhaustive project archive, miscellaneous work gallery

**Minimal magazine style**:
A restrained editorial visual language that uses typography, spacing, hierarchy, and case-study density to make technical ability feel credible and premium.
_Avoid_: Template portfolio, noisy cyberpunk page, decorative AI spectacle

**Editorial engineering blend**:
The site's chosen visual language: WIRED-like editorial density as the main structure, with Vercel-like engineering precision and Claude-like AI product warmth as supporting influences.
_Avoid_: Pure magazine imitation, pure developer platform clone, generic AI startup gradient

**Visual hook**:
The first-screen concept that earns attention before the hiring audience reads the details, while still pointing back to the site owner's AI product interface ability.
_Avoid_: Decorative intro animation, generic tech background, portfolio splash screen

**Interface slice**:
A compact, first-screen product fragment that lets visitors see or lightly interact with an AI workflow, including input, system state, output, and supporting evidence.
_Avoid_: Static mockup, generic chatbot, abstract animation

**English-first bilingual site**:
A site whose primary interface and positioning language is English, with Chinese support for personal context and local hiring opportunities.
_Avoid_: Fully duplicated bilingual site, Chinese-only portfolio, mixed-language clutter

**Hiring conversion**:
The primary next step for the hiring audience: view or download the resume, then contact the site owner by email.
_Avoid_: Social follow, passive browsing, unclear call to action

**Case study spine**:
The standard structure for each selected case: problem, product decision, interface, technical build, and outcome.
_Avoid_: Screenshot-first project card, resume bullet list, unstructured project story

**Source-backed case material**:
Case-study content grounded in the resume, GitHub repositories, and verifiable project artifacts rather than invented portfolio claims.
_Avoid_: Fabricated metrics, unverifiable project stories, generic capability claims

**Flagship case**:
The enterprise customer-service delivery: Udesk external-agent middleware, resumable evaluation, trace diagnosis, and 225-question UI acceptance, used as the strongest proof of FDE scoping, integration, measurement, and handoff.
_Avoid_: Presenting it as a model demo, mixing test sets into one number, claiming client-wide acceptance

**Delivery thread**:
One end-to-end FDE workstream with a business problem, integration surface, evaluation method, and handoff artifact; the selected page currently carries three.
_Avoid_: Feature list, isolated demo, screenshot gallery

**Lark CLI automation**:
Automation experience using Feishu/Lark CLI or API-driven workflows to execute operational tasks, update records, and coordinate work in Feishu surfaces.
_Avoid_: Manual Feishu usage, generic collaboration tooling, unsupported automation claims

**Hermes Lark automation**:
Automation work that combines Hermes-style agent orchestration with Feishu/Lark CLI execution to complete repeated operational tasks.
_Avoid_: Vague agent demo, unverified workflow claim, standalone CLI script

**Base agent application**:
Use of Feishu/Lark Base intelligent agents to turn structured table records into automated decisions, task execution, or workflow updates.
_Avoid_: Plain spreadsheet usage, manual status tracking, unverified video-only claims

**Public contact surface**:
The contact information shown directly on the website: email and GitHub, with phone number omitted from page copy for privacy.
_Avoid_: Public phone-first contact, hidden contact path, social-only conversion

**Public identity**:
The English-facing identity for the site owner: Wenjun You, with Wenjunyun123 reserved as the GitHub handle.
_Avoid_: Informal handle as primary name, inconsistent bilingual naming
